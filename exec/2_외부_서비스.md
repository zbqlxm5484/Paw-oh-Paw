# 2. 외부 서비스

소셜 로그인, 결제, 지도, 푸시 알림은 쓰지 않는다. 로그인은 자체 아이디와 비밀번호(JWT)다.

## 2.1 가입하거나 받아야 하는 것

| 서비스 | 쓰는 곳 | 필요한 것 | 설정하는 자리 |
| --- | --- | --- | --- |
| AWS EC2 (SSAFY 제공) | 팀 서버. 화면, API, 워커, DB | 서버 접속 키(pem), 도메인, 인증서 | 호스트 nginx, GitLab Runner(태그 `docker`) |
| SSAFY GPU 서버 | 분석 API (모델 추론) | 서버 계정, EC2로 여는 SSH 역방향 터널 | GitLab Runner(태그 `gpu-deploy`), `~/service/env` |
| SSAFY GitLab | 소스 저장소, CI/CD | 프로젝트 권한, CI/CD 변수 `ENV_FILE`, `ENV_FILE_DEV` | `.gitlab-ci.yml` |
| SMTP 메일 서버 | 비밀번호 재설정 링크 메일 | STARTTLS(587)를 받는 메일 계정 | `.env`의 `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` |

메일 계정이 없어도 서비스는 돈다. 비밀번호 재설정 요청만 503으로 답한다.

파일은 서버의 Docker 볼륨(`api-data`)에 둔다. 클라우드 저장소(S3 등)는 쓰지 않는다.

## 2.2 가입 없이 쓰는 것

| 서비스 | 쓰는 곳 | 비고 |
| --- | --- | --- |
| Google Fonts | 화면의 로고 글꼴(Fredoka, Nunito) | `frontend/index.html`, `web/index.html`에서 불러온다. 막힌 망에서는 기본 글꼴로 보인다 |
| Docker Hub, GHCR | 빌드와 실행에 쓰는 이미지 | `python:3.11-slim`, `node:22-alpine`, `nginx:stable-alpine`, `postgres:17-alpine`, `redis:7-alpine`, `gotenberg/gotenberg:8` |
| PyPI, npm | 의존성 설치 | `requirements.txt`, `package-lock.json`으로 버전 고정 |

## 2.3 저장소에 들어 있지 않은 자료

| 자료 | 받는 곳 | 두는 자리 |
| --- | --- | --- |
| 관절점 모델 코드와 가중치 | 크림오프 | GPU 서버 `~/models/company-orig` |
| 시연 데이터 폴더 (`demo.json`, 촬영별 분석 결과) | 팀 내부 | `python -m scripts.seed_demo --data <폴더>`의 인자 |

모델 없이도 팀 서버는 띄울 수 있다. `.env`의 `ANALYSIS_API_MODE=mock`이면 견본 결과로 전체 흐름이 돈다.
