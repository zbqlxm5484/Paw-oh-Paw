# 보행 유형 판별 규칙 초안 (F-03)

작성 박규원 · 10-30 · S15P31A404-106 · 다음 단계 (2/3) 판별 함수 구현, (3/3) 맞춰 보기

착지 순서로 평보(WALK)·속보(TROT)·측대보(PACE)를 가르는 규칙이다. 결과는 API 명세의 `gait_type`(`WALK`·`TROT`·`PACE`·`OTHER`)이고, 측대보 통과는 유효 판별의 `GAIT_PACE` 사유로 수치 계산에서 뺀다(`docs/engine/validityRules.md`).

## 1. 입력: 카메라 쪽 두 발뿐

착지·이지 검출 `engine/gait_events.py`(조유진, `detect_pass`)는 통과 하나에서 **카메라 쪽 앞발·뒷발** 두 개의 결과만 낸다. 반대쪽 발은 가려지는 일이 많아 쓰지 않는다(PR-F02-04).

| 값 | 출처 | 뜻 |
| --- | --- | --- |
| `front.stances[]`, `hind.stances[]` | `detect_pass(frames, fps, camera_side)` | 디딤마다 `touchdown`(착지 프레임, 못 봤으면 `None`)·`first_frame`·`last_frame` |
| `front.strides[]`, `hind.strides[]` | 같음 | 착지에서 다음 착지까지(`start`·`end`·`stance_frames`) |
| `fps` | 영상 | 프레임 → 초 |

대각 짝(왼앞+오른뒤)은 직접 볼 수 없다. 대신 **같은 쪽 앞·뒷발의 착지 시차**를 쓴다. 세 보행은 이 값 하나로 갈린다.

## 2. 보행 유형별 정의

같은 쪽 앞·뒷발 위상 `φ` = (뒷발 착지 → 바로 다음 앞발 착지까지 걸린 시간) ÷ (뒷발 보행 주기). 0 이상 1 미만이다.

| 유형 | 네 발 순서 | 같은 쪽 앞·뒷발 `φ` | 디딤 비율(duty) |
| --- | --- | --- | --- |
| 측대보 PACE | 같은 쪽 앞·뒤가 짝으로 동시에 | 0 근처 | 0.5 미만 |
| 속보 TROT | 대각 짝이 동시에 → 같은 쪽 앞·뒤는 반 주기 어긋남 | 0.5 근처 | 0.5 미만 |
| 평보 WALK | 네 발이 따로, 뒤→앞 순서(4박) | 0.25 근처(0.75 도 같은 4박) | 0.5 이상(늘 세 발 이상 디딤) |

디딤 비율 = 디딤 프레임 ÷ 보행 주기 프레임(`stance_frames / (end − start)`), 앞·뒷발 평균.

## 3. 판정 규칙 (처음 값)

통과 하나마다:

1. 뒷발 보행 주기마다 `φ` 를 잰다. 주기 안에 앞발 착지가 없거나 착지를 못 본(`None`) 주기는 건너뛴다.
2. `φ` 는 원 위의 값(0 과 1 이 이웃)이라 **원형 평균** `φ̄` 와 일관성 `R`(0~1, 1 이면 모든 주기가 같은 위상)을 낸다.
3. 디딤 비율 중앙값 `D` 를 낸다.

| 순서 | 조건 | 결과 |
| --- | --- | --- |
| 1 | 앞·뒷발 짝을 이룬 주기 2개 미만, 또는 `fps` < 20 | 판정 불가(`null`) |
| 2 | `R` < 0.7 (주기마다 위상이 제각각) | `OTHER` |
| 3 | `φ̄` 가 0 에서 ±0.12 안 | `PACE` |
| 4 | `φ̄` 가 0.5 에서 ±0.12 안 | `TROT` |
| 5 | `φ̄` 가 0.15~0.40 또는 0.60~0.85, 그리고 `D` ≥ 0.50 | `WALK` |
| 6 | 그 밖(위상은 평보인데 `D` < 0.5 등) | `OTHER` |

촬영 단위 결과는 판정된 통과의 다수결이고, 같은 수면 `OTHER`.

| 기준값 | 처음 값 | 근거 |
| --- | --- | --- |
| 위상 허용 폭 | ±0.12 | 30fps 속보 한 주기 12~15프레임에서 착지 검출이 ±1프레임 흔들리면 위상 ±0.07. 그보다 조금 넓게 |
| 일관성 `R` | 0.7 | 주기 2~4개에서 위상이 ±0.2 안에 모이면 넘는 값 |
| 평보 디딤 비율 | 0.50 | 평보는 세 발 이상 디딤 구간이 있어 한 발 디딤 비율이 절반을 넘는다 |
| 최소 주기 | 2 | 위상을 원형 평균으로 내려면 최소 2개 |

모든 값은 맞춰 보기(3/3)에서 바꾼다. 착지 검출 v0 의 디딤 비율이 낮게 나오는 경향(제니 실측 중앙 약 40%)이 있어 평보 문턱은 특히 다시 봐야 한다.

## 4. 판정 불가와 한계

- 한 통과에 보행 주기가 2개 미만이면 판정하지 않는다. 짧은 화면(작은 매트, 빠른 개)에서 자주 생길 수 있다.
- 카메라 쪽 두 발만 보므로 **같은 쪽 위상만으로 판단**한다. 반대쪽 발이 잘 보이는 촬영에서 대각 짝을 같이 보는 건 다음 단계 후보.
- 뜀걸음(구보)은 유효 판별(뜀·속도 사유)이 먼저 거른다고 보고 여기서 따로 정의하지 않는다. 걸러지지 않고 들어오면 대부분 `OTHER` 로 떨어진다.
- 앰블(빠른 측대 평보)은 위상 0.1~0.2·디딤 0.5 미만이라 `PACE`·`OTHER` 경계에 걸린다. 데이터에 있는지 맞춰 보며 확인한다.
