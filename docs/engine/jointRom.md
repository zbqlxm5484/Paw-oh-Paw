# 관절 가동 범위 (F-02)

작성 조유진 · v1 11-04 (S15P31A404-184) · 코드 `engine/joint_rom.py` · 테스트 `tests/test_joint_rom.py`

통과 하나에서 카메라 쪽 다리 6관절의 가동 범위와 각도 중앙값, 무릎의 주기별 가동 범위를 낸다. 결과 JSON v1(`docs/analysisApi/resultFormat.md`) 3절의 키와 단위 그대로 `passes[].metrics`에 들어간다. 걸음 길이·입각기 비율은 `docs/engine/gaitMetrics.md`다.

## 1. 정의

| 키 | 단위 | 정의 |
| --- | --- | --- |
| `rom_shoulder`·`rom_elbow`·`rom_carpus` | `deg` | 앞발 주기 안 프레임의 굽힘 각도 5백분위와 95백분위 사이 폭 |
| `rom_hip`·`rom_stifle`·`rom_tarsus` | `deg` | 같은 방식, 뒷발 주기 |
| `angle_median_<관절>` | `deg` | 같은 프레임의 각도 중앙값 |
| `stifle_cycle_rom` | `{"values": [...], "unit": "deg"}` | 뒷발 주기마다 무릎 가동 범위(5에서 95백분위 폭). 팀 서비스가 회차의 주기들을 모아 `stifle_cv`(표본 표준편차 ÷ 평균 × 100)를 낸다 |

- 각도는 `engine/angles.py`의 굽힘 각도(`angle_def` v1, 굽히는 쪽 면에서 잰 0에서 360°, 180° 초과는 과신전)다. 관절점 파일의 `angles`와 같은 계산이다
- 최솟값·최댓값 대신 5·95백분위를 쓴다. 관절점이 한두 프레임 튀어도 가동 범위가 흔들리지 않게 하려는 것이다
- **완전한 보행 주기 안의 프레임만 쓴다.** 앞다리 관절은 앞발 주기, 뒷다리 관절은 뒷발 주기다(착지에서 다음 착지 바로 전까지). 주기의 일부만 보면 관절이 덜 움직인 구간만 잡혀 가동 범위가 작게 나오기 때문이다
- 다리는 카메라 쪽만, 프레임은 몸 전체가 화면 안에 보인 것만 쓴다(유효 판별·보행 수치와 같음)
- 걸음 길이와 같은 착지·이지를 쓴다. 분석 API는 착지 검출을 한 번 하고 두 계산에 넘긴다

## 2. 측정 불가

| 사유 | 언제 |
| --- | --- |
| `NOT_ENOUGH_CYCLES` | 그 발의 주기가 없음 |
| `LOW_CONFIDENCE` | 주기 안 프레임 중 세 점(꼭짓점·근위·원위, 확신도 0.3 이상)을 모두 믿을 만한 프레임이 절반이 안 됨 |

## 3. 가상 보행으로 확인

착지 검출 테스트의 가상 보행(60fps, 주기 0.4초)에 무릎 각도를 120 + 20 sin(주기마다 한 바퀴)로 넣었다. 사인파의 5에서 95백분위 폭은 2 × 20 × sin(81°) = 39.5다.

| 수치 | 정답 | 계산 허용 |
| --- | --- | --- |
| `rom_stifle` | 39.5 | ±2 |
| `angle_median_stifle` | 120 | ±2 |
| `stifle_cycle_rom` | 주기 5개, 각 39.5 | 각 ±3 |

점을 넣지 않은 관절은 `LOW_CONFIDENCE`, 짧은 통과는 `NOT_ENOUGH_CYCLES`(0이 아님)인 것도 확인한다.

## 4. 실제 관절점으로 첫 측정 (11-04)

박규원이 만든 제니 관절점(30fps)의 유효 통과. 관절점 파일은 `data/tracks/`에 둔다(저장소에 없음).

| 관절 | `fs-v4` 가동 범위 (통과 수) | `fs-v4-flip` 가동 범위 (통과 수) | 각도 중앙값 (`fs-v4` · `flip`) |
| --- | --- | --- | --- |
| 어깨 | 30.0 (17) | 26.9 (44) | 148.2 · 153.1 |
| 팔꿈치 | 54.6 (17) | 61.9 (44) | 137.5 · 130.9 |
| 앞발목 | 112.5 (17) | 105.8 (44) | 188.4 · 182.2 |
| 고관절 | 34.1 (13) | 41.7 (30) | 131.9 · 129.6 |
| 무릎 | 51.6 (13) | 58.0 (30) | 99.0 · 104.0 |
| 뒷발목 | 54.2 (13) | 51.2 (30) | 116.1 · 116.3 |

- 측정 불가는 모두 `NOT_ENOUGH_CYCLES`(주기를 못 잡은 통과)였고 `LOW_CONFIDENCE`는 없었다
- 무릎 주기별 가동 범위: `fs-v4` 13주기(중앙값 51.6), `flip` 30주기(58.1). 통과당 주기가 많아야 1개라 `stifle_cv`는 회차의 여러 통과를 모아야 나온다
- 앞발목 각도 중앙값이 180°를 넘는다. 디딤 때 앞발목이 뒤로 젖혀지는(과신전) 것과 맞는다
- 두 관절점 파일(같은 개, 다른 모델 설정)의 값이 관절마다 10° 안에서 비슷하다
- 관절 각도 오차(KPI-04)가 관절마다 다르다(기업 모델 기준 앞발목 10.2°, 고관절 9.5°로 가장 큼). 가동 범위도 이 관절들에서 덜 정확할 수 있다
