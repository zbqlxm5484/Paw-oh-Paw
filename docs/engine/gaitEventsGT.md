# 착지·이지 정답 표시와 대조 (KPI-05)

작성 조유진 · 10-29 · S15P31A404-160 · 대조 스크립트 `engine/gait_eval.py`

기업에서 착지 정답(압력 매트 기록 등)을 받을 수 없어서(4차 멘토링), 팀이 영상에 직접 착지·이지 프레임을 표시해 정답을 만든다. 세부명세서도 KPI-05의 정답을 "사람이 영상에서 표시한 시점"으로 정하고 있다.

| KPI | 내용 | 목표 |
| --- | --- | --- |
| KPI-05 | 착지·이지 시각 오차 중앙값 (사람이 영상에서 표시한 시점 대비) | 60fps 기준 2프레임(33ms) 이하 |
| KPI-06 | 걸음 길이 오차 중앙값 (사람이 표시한 착지 발끝 위치 대비) | 몸통 길이 대비 5% 이하 (이 문서 범위 밖) |

## 1. 대상 영상

제니 main 영상(`260820-...-main.mp4`, 30fps)에서 고른다. 박규원이 만든 관절점 `fs-v4.track.json`(26개), `gt_videos.fs-v4-flip.track.json`(72개)에 들어 있는 영상이라 바로 대조할 수 있다.

- 처음에는 6건으로 시작한다. 걸음이 잘 보이는 것과 애매한 것을 섞는다
- 30fps라 1프레임이 33ms다. KPI-05 목표(33ms)가 1프레임과 같으므로, 사람 표시도 1프레임 단위로 정확해야 한다

## 2. 무엇을 표시하나

카메라 쪽 다리의 **앞발과 뒷발**만 표시한다(반대쪽 다리는 가려져 쓰지 않음, PR-F02-04).

| 사건 | 표시할 프레임 |
| --- | --- |
| 착지 `touchdown` | 발끝이 땅에 처음 닿은 프레임. 닿았는지 애매하면 발끝이 더 내려가지 않는 첫 프레임 |
| 이지 `liftoff` | 발끝이 땅에서 처음 떨어진 프레임. 발등이 들리기 시작해도 발끝이 붙어 있으면 아직 아니다 |

- 영상 처음이나 끝에서 잘려 순간이 안 보이는 착지·이지는 표시하지 않는다
- 매트 밖이라도 화면에 보이면 표시한다 (대조 스크립트가 표시한 범위만 비교한다)

## 3. 표시 방법

동영상 플레이어에서 한 프레임씩 넘기며 프레임 번호를 적는다. 프레임 번호는 **0부터** 센다(track 파일과 같음). CVAT에서 보면 화면 아래의 프레임 번호를 그대로 쓰면 된다.

가능하면 **두 사람이 같은 영상을 따로 표시**한다. 대조 스크립트가 사람끼리 차이도 같이 내서, 검출 오차가 사람끼리 차이와 비슷하면 사람 수준이라고 볼 수 있다.

## 4. 정답 CSV 형식

UTF-8, 첫 줄은 열 이름. 한 줄에 사건 하나.

```
video,paw,event,frame,marker
260820-141844-제니-9.8kg-main.mp4,front,touchdown,37,조유진
260820-141844-제니-9.8kg-main.mp4,front,liftoff,46,조유진
260820-141844-제니-9.8kg-main.mp4,hind,touchdown,41,조유진
```

| 열 | 값 |
| --- | --- |
| `video` | track 파일의 영상 이름과 같게 |
| `paw` | `front`(앞발) 또는 `hind`(뒷발) |
| `event` | `touchdown`(착지) 또는 `liftoff`(이지) |
| `frame` | 0부터 센 프레임 번호 |
| `marker` | 표시한 사람. 두 사람이 했으면 이름순 첫 사람을 정답으로, 나머지와는 사람끼리 차이를 낸다 |

`#`로 시작하는 줄은 건너뛴다. **정답 CSV는 기업 영상에서 나온 자료라 저장소에 올리지 않는다.** `data/`(git에 안 올라감) 아래에 둔다.

## 5. 대조 실행

저장소 루트에서:

```
python -m engine.gait_eval --track <track 파일> --gt data/gait_gt.csv --out data/gait_eval.json
```

| 열 | 뜻 |
| --- | --- |
| 정답 | 표시한 사건 수 |
| 맞힘 | 정답 중 ±0.1초 안에 검출이 있는 비율 |
| 오차 | 맞힌 것의 오차 중앙값 (프레임, 밀리초) |
| 더 찾음 | 표시한 범위 안에서 정답과 짝이 없는 검출 수 |
| KPI-05 | 오차 중앙값이 33ms 이하면 통과 (30fps 1프레임 33.34ms는 통과로 봄) |

결과는 Jira S15P31A404-160 댓글에 남기고, 흔들림 창(`SMOOTH_S`)·`STANCE_RATIO`를 바꿔 볼 때마다 같은 정답으로 다시 잰다.
