# 유효 판별 규칙 (F-03)

작성 조유진 · v0 10-23 (S15P31A404-21) · v1 10-30 (S15P31A404-162) · 코드 `engine/validity.py` · 기준값 `engine/validity.yaml`

관절점 시계열(프레임마다 22점 좌표와 확신도)만으로 "이 촬영을 보행 수치 계산에 써도 되는가"를 가르는 규칙이다. 규칙 기반으로 한다(2차 멘토링 Q20: 규칙 기반·학습 방식 모두 허용).

## 0. v1에서 바뀐 것

기업 판별 기준 문서(`NASdata/docs/유무효_판단_기준_문서.md`, 10-22)를 반영했다.

| 항목 | v0 (10-23) | v1 (10-30) |
| --- | --- | --- |
| 우선순위 | 유효를 잘못 버리지 않기(KPI-12) 먼저 | **무효를 잘 잡기(KPI-11) 먼저**, 그다음 KPI-12 (기업 문서 1절) |
| 촬영 판정 | 유효 통과가 없을 때만 무효 | **기업 무효 사유가 붙은 통과가 하나라도 있으면 무효** (기업 문서 1절) |
| 화면 끝 프레임 | 잘린 프레임 비율이 높으면 `PARTIAL_PASS` | 들어오고 나가는 동안 몸이 잘리는 건 정상이라 **검사에서 빼고** 몸 전체가 보인 프레임만 본다 |
| `PARTIAL_PASS` | 이동량·잘림 비율 | 몸 전체가 보인 시간이 짧거나, 나가는 쪽 끝에 닿기 전에 영상이 끝남 ("매트를 완전히 나가지 않음") |
| 측정 구간 | 통과 전체 | **첫 착지부터 마지막 이지** (`measure_start`·`measure_end`, 기업 문서 1절). 매트를 못 찾아서 "매트 안"은 아직 못 봄 |
| 기준값 | 근거 없는 처음 값 | 제니 유효 영상으로 맞춤 (6절) |

## 2. 판별 단위와 공통 값

| 단위 | 뜻 | 결과 |
| --- | --- | --- |
| 통과 | 개가 화면을 한 번 가로질러 지나간 구간 | `passes[].valid`, `reason_code`, `measure_start`·`measure_end` |
| 촬영 | 영상 한 건 | `validity`, `validity_reason` |

- **몸통 길이 L**: T13(2번)과 장골능(13번) 사이 거리(명세서 용어 정의). 거리·속도는 모두 L로 나눈다
- **몸 전체가 보인 프레임**: 개 상자가 화면 끝(2px) 안쪽에 있는 프레임. 통과 검사는 모두 이 프레임으로 한다
- **시간**: 프레임 수를 영상 fps로 나눠 초로 바꾼다 (60, 59.94, 30이 섞여 있음)

## 3. 통과 자르기

기업 `video_kpi.py`의 `find_passes`와 같다. 몸통 두 점의 확신도가 0.3 이상인 프레임을 0.5초 넘게 끊기지 않게 이어, 10프레임 이상이고 몸통 가운데가 화면 폭의 1/3 이상 움직이면 통과 하나로 본다. 진행 방향과 카메라 쪽 다리는 프레임 판정의 다수결이다.

## 4. 사유별 규칙

"상태": **기업** = 기업 도구·문서 값, **팀** = 팀 코드 값, **맞춤** = 제니 유효 영상으로 정한 값, **임시** = 데이터로 아직 확인 못 한 값, **보류** = 방법 미정.

### 4.1 통과 단위

| 코드 | 무엇으로 판단하나 | 기준값 | 상태 |
| --- | --- | --- | --- |
| `NO_DOG` | 통과 구간에서 개를 못 찾은 프레임 비율 | 30% 넘으면 | 임시 |
| `OCCLUDED` | 카메라 쪽 다리 점 중 확신도 0.3 미만이 30% 이상인 프레임의 비율 | 30% 넘으면 | 임시 |
| `OVERLAP` | 사람·다른 동물과 겹침 (안기거나 끌려감 포함) | - | 보류 |
| `NOT_SIDE_VIEW` | 옆모습 프레임(\|가로 차이\| / L 0.5 이상) 비율 | 80% 미만 | 기업(0.5) · 임시(80%) |
| `PARTIAL_PASS` | 몸 전체가 보인 시간, 영상이 끝날 때 상자가 나가는 쪽 끝에서 떨어진 거리 | 0.3초 미만이거나, 끝에서 화면 폭 5%보다 멀 때 영상이 끝남 | 맞춤 (제니 최소 0.33초) |
| `TOWARD_CAMERA` | 통과 처음과 끝의 상자 높이 비율 | 1.35배 넘으면 | 맞춤 (제니 최대 1.28) |
| `NORMALIZATION_LIMIT` | 정규화 v0의 가로 보정 비율 | 1.6 넘으면 | 팀 · 보류 (정규화 연결 뒤) |
| `TURNED` | 반대 방향 프레임 비율, 몸통 가운데가 거꾸로 움직인 시간 | 20% 넘거나 0.3초 넘게 | 임시 |
| `SITTING` | 골반 높이(카메라 쪽 뒷발끝과 장골능의 세로 거리 / L)가 통과 중앙값보다 크게 낮아짐 | 60% 아래로 0.5초 넘게 | 임시 |
| `STOPPED` | 몸통 가운데 속도 | 0.3 L/초 아래로 0.5초 넘게 | 임시 |
| `RUNNING` | 몸통 가운데 속도 중앙값 | 11 L/초 넘으면 | 맞춤 (제니 유효 최대 8.7) |
| `GAIT_PACE` | 같은 쪽 뒷발 착지와 앞발 착지의 위상 차이(주기 대비). 측대보 0, 평보 0.25, 속보 0.5 근처 | 판정 끔 | 보류 |

`GAIT_PACE`를 끈 이유: 제니 유효(속보) 영상에서도 위상이 0.1에서 0.47로 퍼졌다. 몸 전체가 보이는 구간이 0.8초 안팎이라 착지가 두세 번뿐이어서 위상이 흔들린다. 측대보 영상(dogA, 42건)의 관절점을 받아 분포를 본 뒤, 또는 보행 유형 판별(박규원)로 켠다.

### 4.2 촬영 단위

| 코드 | 무엇으로 판단하나 | 기준값 | 상태 |
| --- | --- | --- | --- |
| `NO_DOG` | 영상 전체에서 개를 찾은 프레임 비율 | 5% 미만 | 임시 |
| `MAT_NOT_FOUND` | 매트 위치 검출 | - | 보류 |
| `NO_VALID_PASS` | 유효 통과 수 | 0개 | 명세 |
| `FEW_VALID_PASSES` | 일부 유효일 때 유효 통과 수 | 2개 미만 | 임시 (D-14 뒤) |

촬영 판정 순서:

1. 개를 찾은 프레임이 5% 미만이면 `invalid` + `NO_DOG`
2. 기업 무효 사유(`GAIT_PACE`, `RUNNING`, `TURNED`, `STOPPED`, `SITTING`, `PARTIAL_PASS`, `OVERLAP`)가 붙은 통과가 있으면 `invalid` + 그 사유
3. 유효 통과가 없으면 `invalid` + `NO_VALID_PASS`
4. 촬영 조건 문제(`NOT_SIDE_VIEW`, `OCCLUDED`, `TOWARD_CAMERA` 등)로만 뺀 통과가 있으면 `partial`
5. 그 밖에는 `valid`

## 5. 사유가 여러 개일 때

통과 하나에 사유는 하나다. 다시 찍을 때 먼저 고칠 촬영 조건을 개의 행동보다 앞에 둔다.

```
NO_DOG > OCCLUDED > OVERLAP > NOT_SIDE_VIEW > PARTIAL_PASS > TOWARD_CAMERA
> NORMALIZATION_LIMIT > TURNED > SITTING > STOPPED > RUNNING > GAIT_PACE > GAIT_OTHER
```

## 6. 첫 측정 (10-30)

박규원이 만든 제니 관절점으로 돌렸다. 정답은 manifest `label`을 기업 문서 4절대로 썼다(`trot`·`disease` 유효, `not_trot`·`pace` 무효, `dist`·`_discard`·빈칸 제외).

| 관절점 | 영상 | 무효 잡음 (KPI-11) | 유효를 무효로 (KPI-12) |
| --- | --- | --- | --- |
| `fs-v4.track.json` | 제니 main 26개 중 정답 23개 | 1 / 1 (`not_trot` 1건을 `RUNNING`으로) | 0 / 22 |
| `gt_videos.fs-v4-flip.track.json` | 제니 16촬영 × 카메라 4대 중 정답 64개 | 무효 정답 없음 | 0 / 64 |

- 처음 v1 기준값(v0 그대로)으로는 72개 모두 무효였다. 들어오고 나가는 프레임까지 검사해서 옆모습·잘림·속도가 모두 틀렸다. 몸 전체가 보인 프레임만 보게 고친 뒤 위 결과가 나왔다
- **무효 정답이 1건뿐이라 KPI-11은 아직 판단할 수 없다.** 무효 99건(`not_trot` 57, `pace` 42)의 관절점이 필요하다
- 개 한 마리(제니), 한 날의 영상이다. 다른 개·장소에서 다시 재야 한다
