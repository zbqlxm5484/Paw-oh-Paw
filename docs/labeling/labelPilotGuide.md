# 라벨 맞추기 안내 (10-20, S15P31A404-32)

같은 사진 20장을 각자 라벨링해서, 사람마다 점을 얼마나 다르게 찍는지 재요. 결과로 라벨 기준을 다듬고 주간 라벨 목표량을 정해요. **30분~1시간** 걸려요.

## 1. 접속

1. 크롬에서 팀 채팅에 올린 **CVAT 주소**를 열어요. (규원 노트북의 CVAT예요. 안 열리면 바로 말해 주세요.)
2. **Create an account** 로 가입해요. 비밀번호는 8자 이상이고, 아이디와 비슷하면 거절돼요.
3. 가입한 **아이디를 규원에게 보내 주세요.** 작업(job)을 배정해 드려요.
4. 위 메뉴 **Jobs** 에 배정된 job(`pilot20-A`/`B`/`C` 중 하나)이 보이면 눌러서 열어요.

## 2. 라벨링

- 사진 20장에 점 22개가 **이미 찍혀 있어요**(오토라벨). 틀린 점을 옮기고, 가려진 점을 표시하고, 장마다 등급을 남겨요.
- 규칙은 두 문서를 따라요.
  - 기업 라벨러 가이드: `cvat-labeling/guide/labeler.md` (먼저 읽기, 10분)
  - 우리 보충 기준서: `docs/labeling/labelGuide.md` (특히 2장 "점마다 어디를 찍나", 3장 "Q 규칙")
- 한 장 순서: ① 잘 보이는 쪽 다리 2개 → ② 몸통·머리 → ③ 가려진 쪽 다리 2개(Q) → ④ grade(필요하면 reason) → ⑤ 다음 장(F)

자주 쓰는 키

| 키 | 하는 일 |
|---|---|
| 마우스 휠 / 빈 곳 끌기 | 확대·축소 / 화면 이동. 발끝은 꼭 확대 |
| 점 끌기 | 점 옮기기 |
| `Q` (점 위에서) | 가려짐 켜고 끄기 |
| `O` (점 위에서) | 화면 밖 |
| `F` / `D` | 다음 장 / 이전 장 |
| `Ctrl+S` | 저장 (자주) |

헷갈리기 쉬운 것

- **왼쪽·오른쪽은 개 기준**이에요. 개가 화면 오른쪽을 보면 카메라 쪽 다리가 오른쪽 다리예요.
- 2번(등 가운데)·13번(엉덩이 위)은 **옮기지 마세요.**
- 반대쪽 어깨·고관절은 대부분 몸통에 가려요 → 위치를 추정해 찍고 **Q**.
- 발끝 4개(7·12·17·21)는 **다섯째(바깥쪽) 발가락 끝**이에요.
- **다른 사람 결과는 보지 말고** 혼자 판단해요. 서로 다르게 찍는 걸 재려는 거예요.

## 3. 끝낼 때

1. 20장 모두 grade가 있는지 확인해요(`unreviewed` 가 남으면 안 돼요).
2. `Ctrl+S` → 왼쪽 위 **Menu → Change job state → completed**.
3. **걸린 시간(분)을 규원에게 보내 주세요.** 잠깐 쉰 시간은 빼고요.

## 하지 말 것

- 같은 job을 다른 사람과 동시에 열기
