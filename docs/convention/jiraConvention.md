# Jira 컨벤션

보드: https://ssafy.atlassian.net/jira/software/c/projects/S15P31A404/boards/16681

## 에픽

기업 명세서의 기능 번호를 그대로 쓴다. 9개.

| 에픽 | 이름 |
| --- | --- |
| F-01 | 관절점 정규화 (3차원→2차원) |
| F-02 | 보행 수치 산출 |
| F-03 | 유효 구간 판별과 보행 유형 |
| F-04 | 기존 모델 평가 |
| F-05 | 추론 최적화와 경량화 |
| F-06 | 개선 전후 비교 |
| F-07 | 데이터 등록, 분석 API |
| F-08 | PDF 보고서 |
| F-09 | 결과 조회 웹 |

기능에 안 들어가는 일(환경 구성, 라이선스 검토, 문서)은 에픽 `공통`에 둔다.

## 스토리

- 제목: `[F-0N] 동사로 끝나는 한 줄` (예: `[F-04] 현행 모델 추론 시간을 잰다`)
- 담당자, 스프린트 라벨, 에픽 링크는 비우지 않는다
- 크기는 하루 이틀. 더 크면 쪼갠다
- 브랜치와 MR 제목에 이 번호를 쓴다

## 스프린트

- 1주 단위, 월요일 시작 금요일 종료
- 라벨 `sprint-1`, `sprint-2`, … 로 표시한다
- 월요일 아침에 이번 주 스토리를 고르고, 금요일에 못 끝낸 것을 다음 주로 넘긴다

## 상태

`할 일` → `진행 중` → `리뷰 중` → `완료`. MR을 올리면 `리뷰 중`, 머지되면 `완료`.
