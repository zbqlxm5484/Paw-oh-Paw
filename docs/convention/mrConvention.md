# MR 컨벤션

## 제목

```
<타입>: <제목> (S15P31A404-NN)
```

타입과 제목 규칙은 커밋과 같다. 끝에 Jira 번호를 붙인다.

```
feat: 영상 등록 API 추가 (S15P31A404-12)
```

## 본문

템플릿은 `.gitlab/merge_request_templates/default.md`에 있고 MR을 만들면 자동으로 들어간다. 다섯 절을 다 쓴다. 해당 없으면 비우지 말고 "해당 없음"과 이유 한 줄을 적는다.

| 절 | 무엇을 |
| --- | --- |
| 관련 이슈 | Jira 번호 |
| 무엇을 | 바뀐 것. 세 줄 안쪽 |
| 왜 | 이렇게 한 이유, 다른 방법을 버린 이유 |
| 확인한 방법 | 돌려 본 명령, 결과, 캡처 |
| 봐 줬으면 하는 곳 | 리뷰어가 집중할 파일이나 판단 |

## 리뷰

- 리뷰어 1명 이상. 작성자가 지정한다
- 리뷰는 하루 안에 본다. 늦으면 채팅으로 알린다
- 머지 방식은 squash 없이 merge commit. 작업 브랜치는 머지 뒤 삭제
